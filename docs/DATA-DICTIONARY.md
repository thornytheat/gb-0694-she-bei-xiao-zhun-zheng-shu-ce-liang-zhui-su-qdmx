# 数据定义

证书有效期与量程双约束；参考标准也须在校准时有效，证书撤销向下游传播并检测环。

输入字段：cert, device, alias, parent, valid_from, valid_to, minimum, maximum, unit, revoked, measured_at, value, measure_unit, version。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

校准电压量程闭区间[min,max]，证书日期为半开[valid_from,valid_to)。父证书需在子证书生效日有效；撤销按追溯性撤销处理，所有下游测量拒用。同编号证书定义冲突会使其及下游失去证明力。样例是电压仪器，未处理非线性量程和不确定度传播。

## M8 纠错对象

纠错记录独立于原批次存储于 corrections 表，字段语义：

- `correction_id`：由原回执 run_id + 规则版本 + 纠错原文 SHA256 派生的 16 位幂等键；同内容重跑返回同一 id。
- `source_run_id` / `source_revision`：原回执身份与提交纠错时的复核版本，纠错全过程不改写该回执。
- `corrected_certs`：纠错 CSV 中显式出现的证书；`affected_certs`：上述证书及其追溯链下游（受影响面）。
- `unaffected`：证书不在受影响面的测量，状态固定“沿用原回执”，原结论与修正结论一致。
- `suspended` / `confirmed` / `rolled_back_items`：受影响测量的三个去向桶。受影响测量在确认前状态为“停用待确认”，确认通过后转“已确认更新”并写入修正结论，退回则“退回停用”，回退后进入恢复桶并恢复原结论。
- 每个测量对象带 `原结论/原原因码/修正结论/修正原因码/结论是否变化/停用去向/行号`，测量身份键为（证书, 测量日, 归一化伏特值）。
- `quarantine_delta.纠错新增隔离`：纠错合并复算新引入的隔离行，`纠错来源行` 以 C1..Cn 标记其在纠错 CSV 中的序号。
- `state` 状态机：停用待确认 → 已确认更新 / 退回停用 → 已回退；`revision` 为纠错自身乐观锁，与原批次 revision 相互独立。
- `recomputed` 仅保存重算摘要（run_id、SHA256、规则版本、M6/M7 指标），不复制整份批次，避免与原回执身份混淆。

合并规则为对象级替换：纠错行按 `cert` 覆盖同编号原行、新证书追加，绝不产生同证书重复定义；合并文本仅用于本地离线复算，不回写原批次。
